

## FireFly: Acelerador de Hardware de Alto Rendimiento para Redes Neuronales Espiking con DSP Eficiente y Optimización de Memoria

Este repositorio contiene el código fuente del artículo "FireFly: Un Acelerador de Hardware de Alto Rendimiento para Redes Neuronales Espiking con DSP Eficiente y Optimización de Memoria" publicado en IEEE Transactions on Very Large Scale Integration (VLSI) Systems. El artículo está disponible [aquí](https://ieeexplore.ieee.org/document/10143752).
